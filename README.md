# Армейский марш — фронтенд

Клиентская часть сервиса **«Оценка расстояния дневного перехода армии»**. Одностраничное приложение (SPA) на React. Основная сущность — **род войск** (пехота, кавалерия, обоз, осадная артиллерия) с характеристиками «скорость на равнине» (`speedPlain`) и «питание» (`food`).

В ЛР5 используются mock-данные. В ЛР6–ЛР7 реализована работа с Go-бэкендом через REST API, Redux Toolkit и Axios. Если сервер недоступен, предусмотрена демонстрация с mock-данными.

## Стек

- Vite 8.3.5, React, TypeScript
- React-Bootstrap 2.10.10, Bootstrap 5.3.8
- react-router-dom 7.18.5
- Redux Toolkit, Redux Thunk
- Axios, Swagger / OpenAPI (генерация API-клиента)

## Запуск

```powershell
npm install
npm run dev
```

Приложение открывается на [http://localhost:3000/](http://localhost:3000/) (при используемой настройке Vite).

Для получения реальных данных необходимо отдельно запустить Go-бэкенд и связанные с ним PostgreSQL и MinIO.

## Страницы

Навигация — нижняя панель из четырёх пунктов: **Лента**, **Добавление**, **Плитка**, **Вход**.

### 1. Лента (`/feed`, `/feed/:id`)

Показывает один род войск за раз.

- Изображение и видео рода войск; при отсутствии собственных медиа используются файлы по умолчанию.
- Название, описание, скорость на равнине, потребность в питании и количество лайков.
- Кнопка **«Следующий»** — переход к следующей записи.
- Адрес `/feed/:id` открывает выбранный род войск.
- Для авторизованного пользователя доступна установка и снятие лайка.

### 2. Добавление (`/add`)

Страница создания и публикации рода войск.

- Ввод названия рода войск.
- Добавление изображения и видео.
- Указание описания, скорости на равнине и питания.
- Создание черновика и последующая публикация записи через Go API.
- После публикации новая запись становится доступна в плитке и ленте.

### 3. Плитка (`/tile`)

Список опубликованных родов войск в виде карточек.

- Карточка: изображение, название и характеристики рода войск.
- Переход из карточки к соответствующей записи в ленте.
- Фильтр по скорости и кнопка поиска.
- Для автора своей записи доступно удаление.
- При работающем сервере список загружается через API; при его недоступности могут использоваться mock-данные.

### 4. Вход (пункт «Вход» в нижнем меню)

Форма аутентификации пользователя.

- Поля **«Логин»** и **«Пароль»**.
- Авторизация через Go-бэкенд с использованием JWT.
- Хранение состояния пользователя в Redux Toolkit.
- Хранение JWT-токена в `localStorage` в учебной реализации.
- После входа пользователь может создавать, публиковать и удалять свои записи, а также ставить лайки.

## Структура проекта

| **Путь** | **Назначение** |
| --- | --- |
| `src/pages/military_branch_lenta.tsx` | страница «Лента» |
| `src/pages/military_branch_tile.tsx` | страница «Плитка» |
| `src/types/military_branch.ts` | типы данных рода войск |
| `src/data/military_branches_mock.ts` | mock-коллекция родов войск |
| `src/data/military_branch_api_mapper.ts` | преобразование ответов API для интерфейса |

## Использованные хуки

- `useState` — локальные состояния элементов интерфейса, формы и фильтров;
- `useEffect` — загрузка данных, обновление при переходах и изменении авторизации;
- `useParams` — получение `id` рода войск из маршрута `/feed/:id`;
- `useDispatch` / `useSelector` — отправка действий Redux и получение данных из хранилища;
- `useNavigate` — переходы между страницами.
